# Wireframe Masjid BGC

Dokumen ini berisi rancangan antarmuka (wireframe) untuk halaman atau aplikasi yang berhubungan dengan Masjid BGC. File utama yang tersedia adalah `Wireframe Masjid BGC.html`.

## Tujuan

Wireframe ini dibuat sebagai gambaran awal tata letak dan desain antarmuka sebuah website atau aplikasi masjid, dengan beberapa elemen utama seperti:

- halaman utama / landing page
- informasi tentang masjid
- jadwal kegiatan
- navigasi menu
- area konten utama dan tombol ajakan (CTA)
- tampilan yang lebih modern, bersih, dan mudah dibaca

## File yang Tersedia

- `Wireframe Masjid BGC.html` — file mockup antarmuka berbasis HTML
- `README.md` — dokumentasi singkat mengenai proyek ini

## Deskripsi UI

Wireframe ini dibuat untuk merepresentasikan tampilan website atau aplikasi masjid dengan nuansa yang sederhana, nyaman, dan informatif. Secara umum, komponen yang ada dalam desain ini mencakup:

- header / navbar
- section hero
- menu layanan atau fitur utama
- kartu informasi penting
- bagian aktivitas atau agenda
- footer

## Cara Membuka

1. Buka file `Wireframe Masjid BGC.html` di browser.
2. Pastikan browser Anda mendukung HTML5 dan JavaScript.
3. Jika file dibuka secara lokal, disarankan menggunakan browser seperti Chrome atau Edge agar tampilan lebih konsisten.

## Catatan

- Ini merupakan wireframe, bukan aplikasi backend yang sudah berfungsi penuh.
- Fokus utama dari dokumen ini adalah desain antarmuka dan struktur tata letaknya.
- File ini dapat menjadi referensi untuk pengembangan versi yang lebih lanjut, baik ke Flutter maupun ke aplikasi web.
